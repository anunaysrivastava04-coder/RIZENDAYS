# RIZEN DAYS | Modern Weather Intelligence 🌤️

RIZEN DAYS is a premium, single-page weather web application built for speed, accuracy, and visual elegance. It provides real-time weather forecasting, interactive meteograms, air quality indexing, and smart outdoor recommendations without requiring any user logins, subscriptions, or API keys.

## 🚀 Quick Start

Since RIZEN DAYS is built as a zero-build Single Page Application (SPA), getting started is incredibly simple:

1. Clone or download this repository.
2. Open `index.html` in any modern web browser.
3. *That's it!* No `npm install`, no build steps, and no API keys required.


## 🎯 Design Philosophy
RIZEN DAYS was designed with a "Glassmorphism" aesthetic, prioritizing a clean, distraction-free environment. It dynamically adapts its theme and particle background effects based on the current time of day and weather conditions (e.g., falling rain particles on rainy days, dark blue UI at night).

## 📂 Structure
The entire application is self-contained within `index.html` to ensure maximum portability and zero dependency management.
- **HTML:** Semantic layout and structure.
- **Tailwind CSS:** Handled via CDN for rapid, responsive styling.
- **Vanilla JavaScript:** Manages state, API fetching, local caching, and canvas animations.
