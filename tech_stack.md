# 🛠️ Technology Stack & Libraries

RIZEN DAYS is built to be lightweight and fast, avoiding heavy frameworks in favor of native browser capabilities and optimized CDNs.

### Core Languages
*   **HTML5:** Semantic DOM structure.
*   **CSS3:** Custom animations, keyframes, scrollbar styling, and glassmorphism filters (`backdrop-filter`).
*   **JavaScript (ES6+):** Asynchronous API handling (`async/await`), DOM manipulation, Canvas API for particle physics, and state management.

### Libraries & CDNs
*   **[Tailwind CSS (CDN)](https://tailwindcss.com/):** Used for atomic, utility-first styling and rapid responsive design without a build step.
*   **[Chart.js](https://www.chartjs.org/):** Renders the Interactive Meteogram and 7-day history trends. A custom plugin is written on top of Chart.js to handle the day/night background shading.
*   **[Phosphor Icons (Web)](https://phosphoricons.com/):** Provides the consistent, clean, and customizable SVG icon set used throughout the UI.
*   **[Google Fonts](https://fonts.google.com/):** Utilizes **'Inter'** for highly legible UI text and **'Outfit'** for bold, impactful display headers and temperatures.
